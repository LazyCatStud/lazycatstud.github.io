# В меру — калькулятор КБЖУ готового продукта

Откройте `index.html` в браузере. Установка, сервер и подключение к интернету не нужны.

1. Введите калории, белки, жиры и углеводы **на 100 г сухого / сырого продукта** с упаковки.
2. Укажите вес всей партии до приготовления и после него, без посуды.
3. Справа появится КБЖУ на 100 г готового продукта. Пересчёт работает сразу при вводе.

Можно использовать запятую или точку. Примеры макарон, риса и гречки содержат условные данные: для своего продукта используйте упаковку. В раскрывающихся блоках можно рассчитать порцию и посмотреть КБЖУ всей партии. Кнопка копирования переносит результат в буфер обмена; браузер может ограничить доступ к нему при открытии локального файла.

Формула для каждого показателя:

```text
КБЖУ на 100 г готового = КБЖУ на 100 г сырого × сырой вес / готовый вес
```

Например: 350 ккал на 100 г сухих макарон, 100 г до варки и 250 г после → 140 ккал на 100 г готовых макарон.

Расчёт предполагает сохранение общего КБЖУ. Подходит для приготовления на воде без добавок; масло, молоко и соусы нужно учитывать отдельно. Потери части продукта или питательных веществ при приготовлении делают результат приблизительным. Уменьшение веса тоже поддерживается.

Сайт не отправляет и не сохраняет введённые данные. Внешних зависимостей и сетевых запросов нет.

## Файлы

- `index.html` — страница и интерфейс.
- `styles.css` — адаптивное оформление.
- `calculator.js` — расчёт, проверка ввода, примеры и копирование.
- `calculator.test.cjs` — проверки математики и обработки чисел.
- `favicon.svg` — значок сайта.

Проверка логики (нужен Node.js):

```sh
node --test calculator.test.cjs
```

Необязательный локальный предпросмотр:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

После запуска откройте http://127.0.0.1:8765. Остановить сервер: Ctrl+C.
